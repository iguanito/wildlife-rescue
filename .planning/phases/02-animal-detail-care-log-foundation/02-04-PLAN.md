<!-- What Plan 01 built — the routes being tested. -->

GET /api/animals/:id/carelogs
- Auth: any authenticated user (no requireRole)
- Returns: Array of CareLog documents sorted by date: -1
- Each item populated: createdBy has { email, role }
- Empty array if no logs exist

POST /api/animals/:id/carelogs
- Auth: requireRole('staff', 'vet', 'admin') — volunteer returns 403
- Body: { date: ISO string, type: 'feeding'|'weight'|'observation', value?: string, notes?: string }
- Returns 201: populated CareLog with _id, animal, date, submittedAt, type, value, notes, createdBy: { email, role }
- createdBy is always set from req.user._id (not from body)
- Returns 400 if type is invalid enum value
- Returns 400 if date is missing (required field)

GET /api/animals/:id
- Returns full animal document with: _id, name, species, status, intakeDate, notes, createdAt

GET /api/animals/:id/medical
- Returns array of MedicalRecord documents (may or may not have createdBy populated)
